## 🤖 Machine Learning Explorations

### Regression Fundamentals
**File:** [`salary-prediction-regression-models.ipynb`](https://github.com/TechWhizGenius/Data_Science-Projects/blob/main/ml-algos/notebooks/salary-prediction-regression-models.ipynb)

Exploring the building blocks of supervised learning through three regression techniques:

- **Simple Linear Regression**: Predicting salary from years of experience
- **Multiple Linear Regression**: Understanding business profitability with multiple factors and feature selection  
- **Polynomial Regression**: Capturing non-linear relationships when straight lines aren't enough

**Key concepts covered:** Feature encoding, backward elimination, model evaluation metrics, and comparing linear vs. non-linear approaches.
